# Pharmacogenomic Variant Interpretation

This repository contains the data and resources associated with our work:

F. Pucci, P. Hermans, M. Tsishyn, J. Cusato, and M. Rooman,  
*"Assessing Computational Models for Pharmacogenomic Variant Interpretation"* (2026).  
[BioRxiv preprint](https://www.biorxiv.org/content/10.64898/2026.08.03.742561v1)

## Repository contents

- `DCLI.csv` — DCL dataset used in this study, containing the experimental values of the intrinsic clearance (CLint) of mutant proteins relative to the corresponding wild-type proteins (%), as well as the predictions from the set of computational models tested.
